Privacy policy

Org Assistant is a personal project for its owner’s Org-mode notes, tasks, and agendas.

Data and use

The project accesses file contents and metadata through the Google Drive API to download, create, and update Org files. It uses a dedicated Google account; the owner controls which personal folders are accessible by sharing them with that account. Automatic synchronization and autonomous AI editing are currently disabled.

Storage and sharing

Files, working copies, and versioned backups are stored in Google Drive and on the owner’s computer and private server. OAuth credentials are stored privately, outside the public website and source repository. Data is not sold, used for advertising, or used to train generalized AI models. Google API data use follows the Google API Services User Data Policy, including its Limited Use requirements.

Control and deletion

The owner can revoke Google authorization or stop sharing folders at any time. Existing downloaded copies and backups remain until the owner deletes them. For privacy or deletion questions, contact the owner using the support email shown on the Google authorization screen.

This website

This static site has no forms, analytics, or advertising. GitHub Pages may collect technical information when serving it, as described in GitHub’s privacy statement.
