Privacy policy

Org Assistant is a personal project for its owner’s use.

Data and use

Authorized Google Drive file contents and metadata are accessed solely for the owner’s personal use.

Storage and sharing

Data and backups are retained in Google Drive and private storage controlled by the owner. Credentials are kept private. Data is not sold, used for advertising, or used to train generalized AI models. Google API data use follows the Google API Services User Data Policy, including its Limited Use requirements.

Control and deletion

The owner can revoke Google authorization or stop sharing folders at any time. Existing downloaded copies and backups remain until the owner deletes them. For privacy or deletion questions, contact the owner using the support email shown on the Google authorization screen.

This website

This static site has no forms, analytics, or advertising. GitHub Pages may collect technical information when serving it, as described in GitHub’s privacy statement.
